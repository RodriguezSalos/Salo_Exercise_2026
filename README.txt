# Semana 2 – Hipertrofia (Sitio HTML)

## Cómo usar
1) Descomprime el ZIP.
2) Abre `index.html` en tu navegador (iPhone/iPad/PC).
3) (Opcional) Agrega una imagen de fondo llamada `rocky-summit.jpg` en la misma carpeta.

## Nota sobre el fondo
No se incluye una imagen exacta de Rocky (derechos de autor). Usa una foto tuya o una imagen con licencia/permisos.
